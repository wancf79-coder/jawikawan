# RimbaRia MVP v0.2

Permainan pendidikan teka gambar haiwan untuk kanak-kanak umur 4–8 tahun.

## Kandungan MVP
- 30 haiwan dalam 3 dunia: Ladang, Hutan dan Laut
- 10 soalan setiap sesi
- Bintang, XP, hati dan koleksi haiwan
- Dashboard ibu bapa dengan pintu matematik
- Simpanan kemajuan pada peranti
- Antara muka responsif untuk telefon dan komputer
- Sokongan audio ElevenLabs tanpa API key
- Suara soalan, maklum balas dan 30 nama haiwan
- Empat lagu latar bergilir pada volume rendah
- Muzik turun automatik ketika narator bercakap
- Animasi haiwan, bintang, confetti dan reaksi jawapan
- Butang Muzik ON/OFF dan Suara ON/OFF

## Cara uji
1. Buka index.html dalam Chrome atau Edge.
2. Tekan "Pilih 9 fail".
3. Pilih kelima-lima fail RR dan fail lagu 1.mp3 hingga 4.mp3 serentak.
4. Pelayar akan menyimpan audio pada peranti itu untuk ujian seterusnya.

## Untuk GitHub Pages
Letakkan lima fail suara di audio/voice dan empat lagu di audio/music, kemudian muat naik seluruh kandungan folder ini. Lihat audio/README.txt untuk nama fail tepat.

Nota: MVP menggunakan ilustrasi emoji sementara. Ia boleh diganti dengan imej haiwan profesional pada fasa seterusnya.
