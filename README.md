# JawiKawan MVP

Permainan pembelajaran Jawi dan membaca Bahasa Melayu untuk kanak-kanak umur 5 hingga 8 tahun.

## MVP v0.1

- 30 tahap dalam 3 dunia pembelajaran
- Sistem bintang, XP dan kemajuan
- Arahan suara Bahasa Melayu menggunakan suara peranti
- Profil anak dan dashboard ibu bapa
- Kemajuan disimpan pada peranti
- Boleh dipasang sebagai PWA

Kandungan pendidikan ialah draf MVP dan perlu disemak oleh guru/rujukan DBP sebelum pelancaran awam.
